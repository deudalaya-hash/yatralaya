# यात्रालय (Yatralaya)

A responsive personal travel blog and vlog website featuring **The Spaceship 2.0**, with starter destination sections for Pokhara, Mustang, Rara and Ilam.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
3. The site will be available at `https://deudalaya-hash.github.io/yatralaya/` after deployment completes.

## Notes
- Destination and motorcycle photos are demo images loaded from Unsplash. The bike photo is not a photo of your actual motorcycle.
- Video cards open destination-specific YouTube searches. Replace these with your own vlog URLs when available.
- Travel journal entries are stored only in the current browser using `localStorage`; they are not uploaded or synced.
- This is a static website with no backend or user accounts configured.
